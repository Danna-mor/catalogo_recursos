# Criterios de clasificación

Los recursos académicos podrán clasificarse mediante los siguientes criterios:

1. **Tipo:** libro, artículo, video, sitio web o software.
2. **Tema:** programación, inteligencia artificial, matemáticas, etc.
3. **Nivel:** básico, intermedio o avanzado.
4. **Autor o fuente:** persona, universidad, organización o sitio que proporciona
   el recurso.
