# Alcance del proyecto

El Catálogo de recursos académicos será una aplicación destinada a organizar,
consultar y administrar diferentes recursos educativos.

En una versión futura podría incluir las siguientes funcionalidades:

1. Registrar libros, artículos, videos, sitios web y herramientas de software.
2. Consultar los recursos disponibles.
3. Buscar recursos por título, tema, autor o tipo.
4. Filtrar recursos según el nivel académico.
5. Editar y eliminar recursos registrados.
6. Clasificar los recursos mediante diferentes criterios.
