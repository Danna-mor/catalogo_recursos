# Alcance del proyecto

El Catálogo de recursos académicos será una aplicación destinada a organizar,
consultar y administrar diferentes recursos educativos.

## Funcionalidades previstas
- Registrar tareas.
- Consultar tareas.
- Modificar tareas.
- Marcar tareas como terminadas.
- Mostrar quién asignó una tarea.
- Agregar una opción de prorroga para entrega de tareas.
