# Catálogo de recursos académicos

## Descripción

Proyecto inicial para organizar y consultar recursos académicos como libros,
sitios web, videos, artículos y herramientas de software.

## Objetivo

Crear la estructura inicial de un sistema que posteriormente permita registrar,
clasificar y consultar recursos académicos.

## Estructura

- `app/`: código principal de la aplicación.
- `data/`: información de los recursos.
- `docs/`: documentación y evidencias.
- `tests/`: pruebas del proyecto.
- `README.md`: documentación principal.
- `requirements.txt`: dependencias del proyecto.
- `CHANGELOG.md`: historial de cambios.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Visual Studio Code

## Preparación del entorno

Crear un entorno virtual: .venv
